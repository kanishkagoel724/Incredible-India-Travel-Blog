# 🇮🇳 Incredible India Travel Blog

A multi-page travel blog website exploring the beauty, culture, heritage, and destinations of India through interactive city guides and travel information.

# ✨ About the Project

**Incredible India Travel Blog** is a multi-page travel website created to showcase some of India's popular destinations and provide travelers with useful information about each location.

The website includes a main topic page introducing the beauty and diversity of India, a destinations section featuring 8 cities, individual destination information, a travel guide page, and a Connect With Us page with a traveler registration form.

# 🌍 Destinations

The website features the following destinations:

- 📍 Agra
- 📍 Bangalore
- 📍 Jaipur
- 📍 Nainital
- 📍 Chandigarh
- 📍 Dehradun
- 📍 Mumbai
- 📍 Delhi

Each destination includes its own page with a short description and information about places to visit.

# 📄 Website Pages

### 🏠 Topic Page
Introduces the beauty, culture, heritage, landscapes, and diverse travel experiences of India.

### 🌍 Destinations
Features 8 Indian destinations with images and clickable destination names that lead to individual city information.

### 🧳 Traveler's Guide
Provides short travel guides and useful information for the featured cities.

### 📩 Connect With Us
Includes a traveler registration form where visitors can enter:

- Name
- Address
- Destination
- Contact Number

The page also includes a Thank You section after registration.
